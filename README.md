# Rakin Talukder · Portfolio

Live at **[www.rakin-talukder.me](https://www.rakin-talukder.me)**.

| Folder | What |
|---|---|
| [`v2/`](v2) | The live site (Vite + TypeScript + three.js): a standard page and a 3D desk you can explore as Mi Mao the cat. See [`v2/README.md`](v2/README.md). |
| [`legacy/`](legacy) | The original Flutter site (v1), kept for reference. Not built or deployed. |

Deployed on Vercel: [`vercel.json`](vercel.json) runs [`vercel_build.sh`](vercel_build.sh), which builds `v2/` into `v2/dist`.

```bash
cd v2
npm install
npm run dev   # http://localhost:5173
```
